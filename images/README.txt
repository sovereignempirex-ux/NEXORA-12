NEXORA Website - Images Folder
================================

Required images:
1. icon-*.png files - App icons for PWA (72, 96, 128, 144, 152, 192, 384, 512)
2. screenshot1.png - 1280x720 desktop screenshot
3. screenshot2.png - 750x1334 mobile screenshot

You can generate app icons from your logo using:
- https://favicon.io/
- https://www.pwabuilder.com/imageGenerator

The hero image is already linked externally:
https://i.postimg.cc/PJ1xTdxW/Whats-App-Image-2026-08-01-at-22-22-56.jpg

To use local images, download the image and:
1. Save it as hero.jpg in this folder
2. Update index.html line: src="images/hero.jpg"
